# ACTIVITY-TRACKER

## About The Project

An exercise tracker REST API built with Express and MongoDB (Mongoose). Back-end project for freeCodeCamp's "Back End Development and APIs" certification, per the repository description.

### Built With

- Node.js
- Express
- MongoDB (Mongoose)

## Getting Started

### Prerequisites

- Node.js and npm
- A MongoDB connection string

### Installation

```sh
npm install
```

Copy `sample.env` to `.env` and fill in the values.

### Running

```sh
npm start
```
